HTML DOM

The HTML DOM represents a webpage as a tree of objects. Each HTML element can be considered a node in this tree.

DOM Structure

  • HTML is the root element.
  • Body is a child of HTML.
  • Sections are children of Body.
  • Headings and paragraphs are children of their sections.
